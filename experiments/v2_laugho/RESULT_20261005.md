## Architecture

```
WavLM-base-plus (frozen, 768-dim)
  → Linear(768, 256) → LayerNorm → GELU → Dropout(0.3)
  → Linear(256, 128) → LayerNorm → GELU → Dropout(0.3)
  → Linear(128, 1)
= 1.5M trainable params
```

Loss: `BCEWithLogitsLoss` with `pos_weight = (1 - p_pos) / p_pos` for 1.16% positive rate.
Optimizer: AdamW lr=1e-3, weight_decay=0.01, CosineAnnealing.

- **Different label sources**: AudioSet acoustic laughter (clean) vs StandUp4AI VTT discourse (noisy)
- **Different metrics**: ROC-AUC vs F1 vs IoU-F1@0.2
- **Different n**: 1 shard (~500-2000 laughs) vs 12v gold vs 71v vs 118v
- **Different evaluation set**: speaker-disjoint vs random vs in-distribution

The +0.058 v2 vs v10 humor AUC gap is **suggestive, not evidence of improvement.** It could equally be:
- Genuine improvement (clean acoustic labels help)
- Different sample difficulty (AudioSet is easier than StandUp4AI gold)
- Different metric behavior (ROC-AUC vs AUC on small positive set)

## What this run validates

- ✅ **Architecture works**: 1.5M-param MLP head over frozen WavLM-base-plus extracts laughter signal
- ✅ **AudioSet ontology mapping is correct**: 7 laugh IDs (Laughter, Giggle, Snicker, etc.) filter 500+ rows from 1 shard
- ✅ **5×3 repeated CV methodology is reproducible**: ran end-to-end on Colab T4
- ✅ **ffmpeg-subprocess AAC loader works**: v19 canonical pattern applied
- ✅ **pos_weight for 1.16% positive rate**: model converged, no NaN losses

## What this run does NOT validate

- ❌ **Architecture superiority**: 1 shard vs 12v gold — need common evaluation set for honest comparison
- ❌ **Generalization**: 1 shard from AudioSet eval — need ≥ 5 shards + AMI cross-domain
- ❌ **Label source**: AudioSet acoustic (clean) vs StandUp4AI VTT (noisy) — v2 trained on cleaner labels, so v2 > v10 is expected by construction
- ❌ **Publication headline**: needs ≥ 25 measurements (5×5) with bootstrap CI < 0.10

## Honest conclusion

This run is a **proof of concept**, not a publication. It shows:
1. The pipeline works end-to-end on Colab T4
2. The v2 LaughO architecture extracts signal from acoustic laughter
3. The 5×3 repeated CV protocol produces a result that is traceable + reproducible

To upgrade from proof-of-concept to publication: scale to all 35 AudioSet eval shards + AMI + UR-FUNNY-Temporal, re-run 5×3 CV on the combined dataset, and compare to HaHaScore v10 on a **common** evaluation set (the 12v StandUp4AI gold).
