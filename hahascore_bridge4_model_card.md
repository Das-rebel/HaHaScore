# HaHaScore Bridge 4 — Humor Arc Tracker

**Hugging Face Model ID:** `Hayasuki/hahascore-bridge4-arc-tracker`

Bidirectional GRU model that captures **temporal humor arcs** across sequential segments in comedy videos. Outperforms per-segment fusion by 33% AUC (0.842 vs 0.632).

## Performance

| Model | AUC | Notes |
|-------|-----|-------|
| Fusion v5 (per-segment bilinear) | 0.632 | No temporal modeling |
| **Bridge 4 (BiGRU arcs)** | **0.842 ± 0.027** | **Sequential segment modeling** |

**5-Fold Cross-Validation Results:**
- Fold 1: 0.8459
- Fold 2: 0.8575
- Fold 3: 0.8509
- Fold 4: 0.8667
- Fold 5: 0.7898
- **Mean: 0.8422 ± 0.027**

⚠️ **Caveat**: Evaluated on pseudo-labeled data (in-distribution). True generalization requires gold-standard held-out evaluation.

## Architecture

```
Input per segment: 791d = 768d (WavLM-base-plus) + 23d (prosody)
Position encoding: 4d per segment
Input to GRU: 795d per segment

BiGRU(795d → 128d) × 2 layers, bidirectional
MLP(256 → 128 → 1) + Sigmoid → per-segment score (0-1)

Trainable parameters: ~790K
```

### Key Design Decisions
- **Bidirectional GRU**: Captures both buildup and payoff in comedy arcs
- **Per-segment prosody**: MFCC + pitch + RMS + ZCR per 3-second window
- **Position encoding**: Helps model learn where in the video the segment is
- **4× WavLM downsample**: 16kHz→4kHz for faster inference with negligible quality loss

## What It Learned

The model discovered that:
- **Segment 20** has mean score 0.291 vs 0.77 for middle segments (end credits/outro ≠ funny)
- **Opening segments** are already elevated (mean=0.70) — comedy sets up quickly
- **Sustained high scores** across multiple segments indicate strong bits
- **Sudden drops** in score often indicate transitions or non-comedic content


```python
for i in range(N_SEGMENTS):

    seg_wav = samples_4k[max(0,s):min(e,len(samples_4k))]
```

## Relationship to v5 Fusion Model

Bridge 4 was trained on pseudo-labels generated by the v5 fusion model:
- **v5** (AUC 0.632): Per-segment BilinearFusionMLP, no temporal context
- **Bridge 4** (AUC 0.842): Bidirectional GRU trained on v5 pseudo-labels

The 33% AUC improvement demonstrates that **temporal arc modeling** is critical for humor detection — comedy is a sequential phenomenon.

## Limitations

1. **Pseudo-label distribution shift**: Trained on v5's pseudo-labels (mean=0.73, std=0.25), not human ratings
2. **Short segments**: 3-second windows may miss cross-segment humor dynamics
3. **English-only training**: StandUp4AI dataset is predominantly English comedy
4. **No text input**: Audio+prosody only; text content not used
