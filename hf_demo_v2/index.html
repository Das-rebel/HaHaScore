🤖 How It Works

HaHaScore Cascade v8 uses a multimodal AI architecture that fuses text + audio cues:

📚
Reddit Pretrain
DistilBERT trained on 30K jokes for humor-style priors
🎚️
Audio + Text Fusion

2.9 MB model, ~3ms CPU inference

Segment Analysis

💻 Use the Model in Your Code

import onnxruntime as ort
import numpy as np
from huggingface_hub import hf_hub_download

# Load model
model_path = hf_hub_download(
    repo_id="Hayasuki/hahascore-cascade",
    filename="v8_cascade_int8.onnx"
)
session = ort.InferenceSession(model_path)

# Run inference
text = np.random.randn(1, 20, 768).astype(np.float32)
audio = np.random.randn(1, 20, 791).astype(np.float32)
cross = np.zeros((1, 20, 16), dtype=np.float32)

scores, conf, gate = session.run(None, {
    'text': text, 'audio': audio, 'cross': cross
})
print(f"Average humor: {scores.mean():.3f}")
