💡 About This Demo

This is a static browser-only demo. The text-to-feature encoding uses simple character-level features as a proxy for demo purposes. For full multimodal inference with real text/audio features, use the model directly:

import onnxruntime as ort
import numpy as np

session = ort.InferenceSession("v8_cascade_int8.onnx")
text = np.random.randn(1, 20, 768).astype(np.float32)
audio = np.random.randn(1, 20, 791).astype(np.float32)
cross = np.zeros((1, 20, 16), dtype=np.float32)

scores, conf, gate = session.run(None, {
    'text': text, 'audio': audio, 'cross': cross
})
print(f"Avg score: {scores.mean():.3f}")
